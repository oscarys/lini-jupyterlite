Módulo II Margen Duro y Blando 2 / 8

SVM — Margen Máximo

Formulación: margen duro

min ½‖w‖² s.a. yᵢ(wᵀxᵢ + b) ≥ 1 ∀i Margen geométrico = 2/‖w‖

El SVM elige el hiperplano de máximo margen entre infinitos separadores posibles. Los puntos más cercanos al hiperplano son los vectores soporte.

Margen blando — variables de holgura

min ½‖w‖² + C·Σᵢ ξᵢ s.a. yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ, ξᵢ≥0

El parámetro C

C grandeC pequeño
Penaliza violacionesTolera violaciones
Margen estrechoMargen amplio
Modelo complejoMás regularizado
Puede sobreajustarPuede subajustar

Vectores soporte

Solo los puntos en el margen o dentro de él determinan el hiperplano. Los demás puntos pueden eliminarse sin cambiar la solución — el SVM es una solución dispersa en el espacio dual.

Ref: Cortes, C. & Vapnik, V. (1995). Support-vector networks. Machine Learning, 20(3), 273–297. doi:10.1007/BF00994018

Módulo II El Truco del Kernel 3 / 8

El Truco del Kernel

Idea central

El SVM dual depende solo de productos internos ⟨xᵢ, xⱼ⟩. Un kernel calcula el producto interno en un espacio de características de alta dimensión sin calcular el mapeo explícitamente:

k(xᵢ, xⱼ) = ⟨φ(xᵢ), φ(xⱼ)⟩

Kernels principales

KernelFórmulaFrontera
LinealxᵢᵀxⱼHiperplano
Polinomial(γxᵢᵀxⱼ+r)ᵈPolinómica grado d
RBFexp(−γ‖xᵢ−xⱼ‖²)Arbitrariamente compleja

γ en el kernel RBF

  • γ grande → frontera muy irregular → sobreajuste
  • γ pequeño → frontera suave → subajuste
  • γ='scale' → 1/(d·Var(X)) — buen punto de partida

Función de Mercer

Un kernel válido debe ser simétrico y semidefinido positivo — equivalente a existir un espacio de Hilbert con reproducción del núcleo (RKHS) donde el kernel calcula el producto interno.

Módulo II Aplicación BCI — Deletreador P300 5 / 8

Deletreador P300 — BCI con SVM

El problema

El usuario observa una matriz de caracteres. Cada fila/columna se ilumina aleatoriamente. El carácter deseado produce un potencial evocado P300 (~300 ms post-estímulo) en el EEG parietal.

Características

  • 40 características: amplitud media en 5 ventanas × 8 canales
  • Desbalance 1:6 (60 target vs 360 non-target)
  • Variabilidad alta entre ensayos — necesita clasificador robusto

¿Por qué SVM en BCI?

  • N pequeño (decenas de ensayos por sesión)
  • d moderado-alto (40–120 características)
  • El margen máximo regulariza implícitamente
  • SVM lineal es el baseline histórico en P300

Ref: Blankertz, B. et al. (2011). Single-trial analysis and classification of ERP components. NeuroImage, 56(2), 814–825. doi:10.1016/j.neuroimage.2010.06.048

Módulo II SVM vs Regresión Logística 6 / 8

¿Cuándo usar SVM vs Regresión Logística?

Criterio Regresión Logística SVM
N grande, d moderado✅ Rápida, escala bien⚠ Lenta con kernel
N pequeño, d grande⚠ Puede sobreajustar✅ Margen regulariza
Probabilidades calibradas✅ Directo⚠ Requiere Platt scaling
Datos no lineales⚠ Features manuales✅ Kernel RBF
Interpretabilidad✅ Coeficientes directos⚠ Solo con kernel lineal
EEG/BCI (N pequeño)✅ Con regularización✅ Preferido en literatura
UCI clínica (N moderado)✅ Interpretable, calibrado✅ Competitivo con RBF

Diferencia matemática fundamental

La regresión logística minimiza la pérdida logística sobre todos los puntos. El SVM solo depende de los vectores soporte — los puntos bien clasificados no contribuyen al gradiente una vez fuera del margen.

Esto hace al SVM más robusto a outliers en algunos regímenes, pero menos eficiente con N grande.

Regla práctica para señales biomédicas

  • EEG/P300/BCI → SVM lineal o LR como baseline
  • ECG/series temporales → LR sobre características HRV
  • fMRI (d >> N) → SVM lineal con C pequeño
  • Tabular clínico (UCI, diagnóstico) → LR + ensambles (S08)
  • Siempre comparar con permutaciones (S04)
