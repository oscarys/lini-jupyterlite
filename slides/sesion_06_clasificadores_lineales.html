Módulo II Regresión Logística 3 / 8

Regresión Logística — Derivación de la Pérdida

Modelo probabilístico

P(y=1|x,w) = σ(wᵀx + b) = 1/(1 + e^{-(wᵀx+b)}) σ(z) ∈ (0,1) para todo z ∈ ℝ

Pérdida: entropía cruzada binaria

Negativo del log de la verosimilitud:

ℒ(w) = -(1/N) Σᵢ [yᵢ log p̂ᵢ + (1-yᵢ) log(1-p̂ᵢ)]

Gradiente

∇_w ℒ = (1/N) Xᵀ(p̂ - y)

Elegante: el gradiente es el error de predicción ponderado por las características. La misma forma que la regresión lineal ordinaria.

Interpretación clínica

Un coeficiente positivo (p. ej. APACHE-II) significa que aumentar esa variable eleva el logit → eleva la probabilidad de muerte. El coeficiente es el cambio en el log-odds por unidad de la característica.

En Python (desde cero)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def gradiente(X, y, w, b):
    p = sigmoid(X @ w + b)
    gw = X.T @ (p - y) / len(y)
    gb = (p - y).mean()
    return gw, gb

Conexión con Módulo I

La entropía cruzada es exactamente el negativo del log de la verosimilitud binomial. La regresión logística es la EMV bajo el modelo de Bernoulli — derivada directamente del Módulo I.

Módulo II Optimizadores: GD, SGD y Adam 4 / 8

GD, SGD y Adam

OptimizadorActualizaciónCaracterística
GD w ← w − η∇ℒ Todo el dataset por paso. Suave pero lento.
SGD w ← w − η∇ℒ_batch Mini-lotes. Ruidoso pero escala bien.
Adam w ← w − η·m̂/(√v̂+ε) Tasa adaptativa por parámetro. Robusto.

Adam — momentos de primer y segundo orden

m_t = β₁·m_{t-1} + (1-β₁)·g_t ← media móvil del grad. v_t = β₂·v_{t-1} + (1-β₂)·g_t² ← media móvil del grad.² m̂_t = m_t/(1-β₁ᵗ) v̂_t = v_t/(1-β₂ᵗ) ← corrección de sesgo w ← w − η·m̂_t/(√v̂_t + ε)

Hiperparámetros por defecto: β₁=0.9, β₂=0.999, ε=10⁻⁸, η=0.001

Trayectorias de convergencia

Regla práctica

  • Adam es el punto de partida recomendado para redes neuronales y logística
  • SGD con momentum puede superar a Adam en algunos casos con buen tuning
  • GD útil para entender convergencia teórica, poco práctico en datasets grandes
Módulo II Regularización L1 y L2 5 / 8

Regularización L1 vs L2

Pérdida regularizada

ℒ_reg(w) = ℒ(w) + λ·Ω(w) L2 (ridge): Ω = ‖w‖₂² → prior gaussiano L1 (lasso): Ω = ‖w‖₁ → prior de Laplace

¿Por qué L1 produce ceros exactos?

Las esquinas de la bola L1 tocan los ejes. La bola L2 es suave — los mínimos raramente tocan los ejes.

Equivalencia bayesiana

RegularizaciónPrior bayesianoEfecto
L2Gaussiano p(w)∝e^{-λ‖w‖²}Shrinkage uniforme
L1Laplace p(w)∝e^{-λ‖w‖₁}Selección de características

La regularización L2 es exactamente la estimación MAP con prior gaussiano — derivada directamente del Módulo I.

Selección de λ

  • λ=0: EMV (sin regularización) — puede sobreajustar
  • λ→∞: todos los coeficientes → 0 — subajuste severo
  • λ óptimo: validación cruzada en el rango [10⁻⁴, 10²]

Contexto UCI

Con 8 características clínicas, L1 puede identificar cuáles son realmente predictivas de mortalidad. El APACHE-II y Glasgow típicamente tienen los coeficientes más grandes.

Softmax Multiclase y Diagnóstico

Función softmax

P(y=k|x) = exp(wₖᵀx+bₖ) / Σⱼ exp(wⱼᵀx+bⱼ)

Generaliza la sigmoide al caso K > 2. La suma de probabilidades es 1 por construcción.

Aplicación UCI — 3 niveles de gravedad

ClaseDescripción
0 — Bajo riesgoSobrevive sin complicaciones mayores
1 — Riesgo intermedioSobrevive con complicaciones
2 — Alto riesgoFallece en UCI

Pérdida categórica

ℒ = -(1/N)ΣᵢΣₖ yᵢₖ log p̂ᵢₖ

Gradiente: ∂ℒ/∂W = Xᵀ(P̂ − Y) / N — misma forma elegante que el caso binario.
