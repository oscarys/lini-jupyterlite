PCA — Análisis de Componentes Principales

Fundamento matemático

PCA busca las direcciones de máxima varianza mediante la descomposición en valores propios de la covarianza:

Σ = (1/(N-1)) XᵀX = WΛWᵀ Z = XW (proyección) Varianza CP_k = λ_k / Σλ_i

Gráfica de codos — EEG 64 canales

Ref: Bishop (2006). PRML §12.1. Springer.

Cuándo usar PCA

  • Visualización en 2D/3D de datos de alta dimensión
  • Compresión de señales multi-canal (EEG, fMRI)
  • Eliminación de ruido por truncamiento de componentes
  • Decorrelación de características como preprocesamiento

⚠ Limitación crítica

PCA no usa las etiquetas de clase. Las primeras componentes explican la mayor varianza — que puede ser ruido o artefactos, no señal útil para clasificación.

Módulo I PCA vs LDA 3 / 8

PCA vs LDA — No supervisado vs Supervisado

PCA — máxima varianza

w* = argmax Var(Xw) = eigenvec(Σ)

No usa etiquetas. Las direcciones de mayor varianza no son necesariamente las más discriminativas.

LDA — máxima separabilidad

w* = argmax (wᵀ S_B w)/(wᵀ S_W w) = eigenvec(S_W⁻¹ S_B)

S_B = dispersión entre clases. S_W = dispersión dentro de clases. LDA maximiza la ratio señal/ruido entre clases.

Limitaciones del LDA

  • Solo K−1 discriminantes para K clases
  • Falla si N < d (necesita regularización)
  • Asume gaussianidad intra-clase
  • Requiere etiquetas → no sirve en inferencia

Comparación visual

Regla práctica

Para clasificación: LDA casi siempre supera a PCA porque usa las etiquetas. Para visualización sin etiquetas o compresión: PCA es la opción.

En la práctica EEG: PCA primero (eliminar ruido, reducir de 64 a ~30 componentes) → LDA después (discriminar clases).

Módulo I ICA — Separación Ciega de Fuentes 4 / 8

ICA — Separación de Fuentes y Artefactos EEG

Modelo de mezcla lineal

x = A·s → s = W·x = A⁻¹·x x: señales observadas (electrodos) s: fuentes independientes A: matriz de mezcla (desconocida)

Independencia estadística

ICA maximiza la no-gaussianidad de las fuentes estimadas (equivalente a minimizar la información mutua entre ellas). Algoritmos: FastICA, InfoMax, JADE.

Flujo de trabajo en EEG

1. PCA

Reducir a ~30 componentes (eliminar ruido)

2. ICA

Separar fuentes independientes

3. Identificar

EOG, ECG, EMG por topografía y morfología

4. Suprimir

Poner a cero las componentes de artefacto

5. Reconstruir

x̂ = A·s̃ (proyectar de vuelta a electrodos)

Fuente: Delorme, A. & Makeig, S. (2004). EEGLAB. J. Neurosci. Methods, 134(1), 9–21. doi:10.1016/j.jneumeth.2003.10.009

Métodos de Selección de Características

Tres familias

FamiliaMétodoVentajaLimitación
FiltroIM, ANOVA, χ²Rápido, agnósticoNo considera interacciones
EnvolventeRFE, SFS, SBSInteraccionesCostoso, sobreajuste
IncrustadoLASSO, RF import.EficienteEspecífico del modelo

Información mutua

I(X;Y) = Σ p(x,y) log[p(x,y)/(p(x)p(y))]

Mide la dependencia estadística general — detecta relaciones no lineales que ANOVA no puede.

RFE (Eliminación Recursiva)

mientras |feats| > n_top: importancias = eval_importancia(X[:,feats]) eliminar feats[argmin(importancias)]

Ref: Guyon & Elisseeff (2003). JMLR, 3, 1157–1182.

⚠ Regla de oro: selección DENTRO del fold

La selección de características debe realizarse dentro de cada fold de la validación cruzada. Realizarla antes introduce fuga de información.

Conceptos clave

  • PCA — valores propios, varianza explicada, gráfica de codos
  • LDA — S_B, S_W, problema generalizado de valores propios
  • ICA — mezcla lineal, independencia estadística, FastICA
  • Selección: filtro (IM, ANOVA), envolvente (RFE), incrustado

Reglas de oro del Módulo I

  • ICA separa fuentes, PCA decorrelaciona — no es lo mismo
