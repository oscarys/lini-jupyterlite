Módulo VPreentrenamiento BERT2 / 8

BERT — Modelado de Lenguaje Enmascarado

Dos objetivos de preentrenamiento

1. MLM (Masked Language Modeling): 15% de tokens enmascarados → el modelo los predice usando contexto bidireccional completo.

2. NSP (Next Sentence Prediction): dadas 2 oraciones, predecir si la segunda sigue naturalmente a la primera.

Estrategia de enmascaramiento (80/10/10)

15% de tokens seleccionados: 80% → [MASK] 10% → token aleatorio 10% → sin cambio (token original)

¿Por qué no enmascarar siempre con [MASK]?

Si solo se usara [MASK], el modelo nunca vería [MASK] durante la inferencia (fine-tuning), creando un desajuste train/test. La variación 80/10/10 fuerza al modelo a construir representaciones contextuales robustas para todos los tokens, no solo los enmascarados.

Devlin, J. et al. (2019). BERT. NAACL.

Ajuste fino parcial (partial fine-tuning)

Congelar las capas inferiores (que codifican sintaxis general) y solo ajustar las capas superiores + clasificador. Reduce el riesgo de sobreajuste y el costo computacional, especialmente con datasets clínicos pequeños.

Línea base sin GPU/transformers

TF-IDF + Regresión Logística sigue siendo una línea base sólida y rápida cuando HuggingFace no está disponible — buena práctica reportar ambos resultados.

Módulo VModelos Fundacionales de EEG — BENDR5 / 8

BENDR — "BERT para EEG"

Pipeline de preentrenamiento autosupervisado

1. EEG crudo → Encoder convolucional
   (dilataciones 1,2,4 — campo receptivo amplio)
2. Cuantizar latentes → codebook discreto
3. Enmascarar tramos de latentes (~6.5%)
4. Transformer de contexto predice
   los tramos enmascarados

Sin etiquetas necesarias

El preentrenamiento usa solo EEG crudo sin anotar — exactamente como BERT con texto sin etiquetar. Las representaciones aprendidas luego se ajustan finamente en tareas específicas (crisis, sueño) con pocas etiquetas.

Inspiración: wav2vec 2.0

BENDR adapta la arquitectura de wav2vec 2.0 (originalmente para habla) al dominio de EEG — otro ejemplo de transferencia de arquitecturas entre dominios de señales temporales.

Kostas, D. et al. (2022). BENDR: EEG foundation model using contrastive self-supervised learning.

Módulo VEficiencia de Datos con Preentrenamiento6 / 8

Por Qué Importan los Modelos Fundacionales

El problema central en biomedicina

Anotar datos clínicos requiere tiempo de expertos (cardiólogos, neurólogos) — extremadamente costoso. Un modelo entrenado desde cero necesita cientos o miles de ejemplos para alcanzar utilidad clínica.

La ventaja del preentrenamiento

Un modelo preentrenado (ClinicalBERT, BENDR) ya "sabe" estructura general del lenguaje clínico o de la señal EEG. El ajuste fino solo necesita aprender el mapeo específico a la tarea — 5-10× menos etiquetas para el mismo rendimiento.

Régimen de pocos datos

La ventaja es más dramática con <100 ejemplos etiquetados — exactamente el escenario típico en investigación clínica de un solo centro.
