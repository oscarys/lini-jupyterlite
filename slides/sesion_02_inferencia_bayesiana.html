Actualización secuencial

El posterior de hoy es el prior de mañana. Conforme llegan nuevos datos, las creencias se actualizan de forma coherente y acumulativa.

Ejemplo: detector de FA

Sens=97%, Espec=96%, Prevalencia=2%

p(+) = 0.97×0.02 + 0.04×0.98 = 0.0586 VPP = 0.97×0.02 / 0.0586 = 33.1%

A pesar de que el test es excelente, solo 1 de cada 3 positivos realmente tiene FA a esta prevalencia.

La evidencia p(𝒟)

Es la constante de normalización que garantiza que el posterior integre a 1. En muchos modelos es intratable analíticamente → necesitamos MCMC o inferencia variacional.

Módulo I Par Conjugado Beta-Binomial 3 / 8

Conjugación Beta-Binomial

Actualización exacta

Si el modelo es Bernoulli y el prior es Beta, el posterior es también Beta:

Prior: p(θ) = Beta(α, β) Datos: m éxitos en N ensayos Posterior: p(θ|𝒟) = Beta(α+m, β+N-m)

Interpretación: α y β actúan como conteos pseudo-observados previos.

PriorSignificado
Beta(1,1)Uniforme — ignorancia completa
Beta(10,10)Esperamos θ≈0.5 con moderada certeza
Beta(1,9)Esperamos θ bajo (p. ej. tasa de eventos raros)

Propiedad clave

Con datos suficientes, todos los priors convergen al mismo posterior. La verosimilitud aplasta el prior cuando N → ∞.

Media y varianza del posterior

E[θ|𝒟] = (α+m) / (α+β+N) Var[θ|𝒟] = E[θ|𝒟]·(1-E[θ|𝒟]) / (α+β+N+1)

La varianza decrece como 1/N — la incertidumbre se reduce con más datos.

Aplicación: sensibilidad de un biomarcador

Estimamos la sensibilidad θ de un biomarcador de sepsis observando pacientes con sepsis confirmada. El cuaderno muestra cómo los tres priors (uniforme, optimista, pesimista) convergen al mismo posterior con N=60.

En Python

from scipy import stats
# Posterior después de m éxitos en N
a_post = a0 + m
b_post = b0 + (N - m)
post   = stats.beta(a_post, b_post)
media  = post.mean()
ic95   = post.interval(0.95)
Módulo I Gaussiana-Gaussiana y MAP 4 / 8

Conjugación Gaussiana y Regularización

Actualización Gaussiana-Gaussiana

Con prior gaussiano sobre la media y datos gaussianos de varianza conocida:

Prior: p(μ) = 𝒩(μ₀, σ₀²) Post: p(μ|𝒟) = 𝒩(μ_N, σ_N²) 1/σ_N² = 1/σ₀² + N/σ² μ_N = σ_N²·(μ₀/σ₀² + N·x̄/σ²)

Media posterior = promedio ponderado

μ_N = w_prior·μ₀ + w_datos·x̄ w_prior = (1/σ₀²)/(1/σ₀²+N/σ²) w_datos = (N/σ²) /(1/σ₀²+N/σ²)

Con N pequeño: μ_N ≈ μ₀ (prior domina)
Con N grande: μ_N ≈ x̄ (datos dominan)

MAP ↔ Regularización L2

Maximizar el log-posterior con prior gaussiano:

log p(θ|𝒟) = log p(𝒟|θ) + log p(θ) = log p(𝒟|θ) - ‖θ‖²/(2τ²)

Equivalencia directa

Perspectiva bayesianaPerspectiva frecuentista
Prior gaussiano p(θ)Penalización L2 (ridge)
Prior Laplace p(θ)Penalización L1 (lasso)
Prior estrecho (τ↓)λ grande — más regularización
Prior uniforme (τ→∞)λ=0 — EMV exacto

Aplicación clínica

Estimación del QTc medio bajo un nuevo antiarrítmico. Prior basado en valores de referencia (μ₀=410ms). Con solo N=1–5 pacientes, el prior evita estimaciones extremas.

Módulo I La Falacia de la Tasa Base 5 / 8

VPP, VPN y la Falacia de la Tasa Base

Definiciones

VPP = P(E|+) = Sens·Prev / P(+) VPN = P(Ē|-) = Espec·(1-Prev) / P(-) P(+) = Sens·Prev + (1-Espec)·(1-Prev)

⚠ La falacia (Casscells et al., NEJM 1978)

Se preguntó a médicos de Harvard: "Si una prueba tiene 5% de falsos positivos y la prevalencia es 1/1000, ¿cuál es la probabilidad de enfermedad dado un positivo?"

La respuesta correcta es ~2%. La mayoría respondió 95% — confundieron especificidad con VPP.

VPP interactivo

5%

¿Por qué el VPP colapsa?

Con prevalencia baja, aunque la tasa de falsos positivos sea pequeña, el número absoluto de FP supera enormemente al de VP.

Ejemplo con Sens=97%, Espec=96%, Prev=2%:

VP (positivos reales)
194
FP (falsos positivos)
392

De 586 positivos totales, solo 194 (33%) son reales.

VPN casi siempre es alto

Con prevalencia baja, un resultado negativo casi siempre significa ausencia de enfermedad. El VPN es un resultado más confiable que el VPP en estas condiciones.

Implicación clínica

Usar pruebas de alta especificidad para confirmar (VPP↑) y pruebas de alta sensibilidad para descartar (VPN↑). La prevalencia del contexto clínico es inseparable de la interpretación.

Módulo I EMV vs MAP vs Bayesiana Completa 6 / 8

¿Cuándo usar cada enfoque?

Método Qué estima Ventaja Limitación Cuándo usarlo
EMV Punto θ̂ que maximiza p(𝒟|θ) Simple, escalable, sin prior Sin incertidumbre; sobreajusta con N pequeño N grande, prior desconocido
MAP Punto θ̂ que maximiza p(θ|𝒟) Incluye prior; misma complejidad que EMV Solo el modo; ignora la forma del posterior Prior disponible, N moderado
Bayesiana completa Distribución posterior completa p(θ|𝒟) Cuantifica incertidumbre completa; óptima con N pequeño Costosa computacionalmente; requiere prior N pequeño, decisiones críticas, prior informativo

Regla práctica

  • N > 1000 y prior débil → EMV ≈ MAP ≈ Bayesiana
  • N < 30 → el prior importa, usar MAP o bayesiana
  • Decisión clínica crítica → siempre cuantificar incertidumbre
  • Prior de literatura → MAP es la opción más económica

En aprendizaje automático

  • EMV = entrenamiento estándar de redes neuronales
  • MAP = entrenamiento con regularización L1/L2
  • Bayesiana = redes neuronales bayesianas (BNN), dropout como aproximación variacional
  • ELBO = objetivo de entrenamiento de VAEs
