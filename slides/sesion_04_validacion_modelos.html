Módulo I Descomposición Sesgo-Varianza 2 / 8

El Compromiso Sesgo-Varianza

Descomposición del error

E[(y - ŷ)²] = Sesgo²[ŷ] + Var[ŷ] + σ² ↑ ↑ ↑ sistemático sensibilidad irreducible

El dilema

  • Modelo simple → sesgo alto, varianza baja → subajuste
  • Modelo complejo → sesgo bajo, varianza alta → sobreajuste
  • Óptimo → minimiza sesgo² + varianza

Diagnóstico con curvas de aprendizaje

SíntomaDiagnósticoSolución
Error train y val altosSesgo altoMás complejidad
Error train bajo, val altoVarianza altaMás datos / regularizar
Ambos bajosBien ajustado—

Aplicación en señales biomédicas

En clasificación EEG/ECG con pocas muestras por sujeto (N=20–100), la varianza domina. Métodos de regularización, modelos simples y validación cuidadosa son esenciales.

Ruido irreducible

El ruido biológico (variabilidad intrínseca de las señales EEG, ECG) es irreducible. Ningún modelo, por complejo que sea, puede eliminarlo — solo aprender a pesar de él.

k-fold vs LOSO — ¿Cuál usar?

Visualización de las estrategias

Ref: Blankertz, B. et al. (2007). The non-invasive Berlin Brain–Computer Interface: Fast acquisition of effective performance in untrained subjects. NeuroImage, 37(2), 539–550. doi:10.1016/j.neuroimage.2007.01.051

⚠ El problema del k-fold en BCI

Con 10 sujetos × 40 ensayos, k-fold mezcla ensayos del mismo sujeto entre train y test. El modelo aprende la firma fisiológica individual, no la tarea cognitiva.

Resultado: exactitud inflada 15–30 puntos porcentuales respecto al rendimiento real.

EstrategiaCuándo usar
k-foldMuestras i.i.d. (tabular, sin estructura de sujeto)
k-fold estratificadoDesbalance de clases
LOSOSeñales fisiológicas multi-sujeto
Ventana deslizanteSeries temporales (sin solapamiento train/test)
CV anidadaSelección de hiperparámetros + evaluación

LOSO — interpretación clínica

LOSO evalúa la generalización a sujetos nuevos — el único escenario clínicamente relevante. Un clasificador de FA que funciona bien solo en sujetos ya vistos no tiene utilidad práctica.

En Python

# LOSO correcto
for sujeto in sujetos_unicos:
    mask_te = ids == sujeto
    X_tr = X[~mask_te]
    X_te = X[ mask_te]
    # normalizar con stats de train
    mu = X_tr.mean(0)
    X_tr = (X_tr - mu) / std
    X_te = (X_te - mu) / std

Regla fundamental

Módulo I Comparaciones Múltiples 5 / 8

El Problema de las Comparaciones Múltiples

El problema

Con m pruebas de hipótesis simultáneas:

P(al menos un FP) = 1 − (1−α)ᵐ ≈ mα m=20, α=0.05 → P(FP) ≈ 64% m=100, α=0.05 → P(FP) ≈ 99.4%

Correcciones

MétodoControlaUmbralPotencia
Sin correcciónNadaαAlta (demasiado)
BonferroniFWERα/mBaja (muy conservador)
B-H (FDR)FDRVariableIntermedia (recomendado)

Ref: Benjamini, Y. & Hochberg, Y. (1995). Controlling the false discovery rate. JRSS-B, 57(1), 289–300.

Algoritmo Benjamini-Hochberg

# Ordenar p-valores
p_ord = sort(p_valores)
m     = len(p_valores)

# Umbral para cada rango k
umbral_k = α × k / m

# Rechazar p_k ≤ umbral_k
k_max = max k: p_ord[k] ≤ umbral_k
rechazar los primeros k_max

Contexto biomédico

Ejemplo: análisis de activación fMRI con 10,000 vóxeles, 200 con activación real (d=0.6):

MétodoVPFPFDR obs.
Sin corrección~131~468~78%
Bonferroni~60~0~0%
FDR (B-H)~120~5~4%

FWER vs FDR

FWER (Bonferroni): cero falsos positivos — correcto cuando cada falso positivo tiene consecuencias graves (p. ej. aprobación de un fármaco).

FDR (B-H): acepta una proporción pequeña de FP a cambio de mucha más potencia — correcto en exploración (neuroimagen, genómica).

Módulo I Prueba de Permutaciones 6 / 8

Prueba de Permutaciones

El algoritmo

1. Calcular T_obs (p. ej. AUROC con LOSO) 2. Repetir B veces: a. Permutar etiquetas b. Calcular T_b con el mismo pipeline 3. p-valor = #{b : T_b ≥ T_obs} / B

Ventajas sobre las pruebas paramétricas

  • Válida para cualquier estadístico (AUROC, exactitud, F1)
  • No asume distribución de los datos
  • Respeta la estructura del pipeline completo
  • Estándar de referencia en BCI y neuroimagen

Permutación restringida

Para datos multi-sujeto, permutar dentro de cada sujeto (no globalmente). Esto preserva la estructura de correlación temporal y espacial, generando una distribución nula más apropiada.

Cuándo usar cada enfoque

SituaciónPrueba recomendada
Distribución conocida, N grandet-test, z-test
Distribución desconocidaPermutaciones
Comparar dos AUROCs, mismos pacientesDeLong (Sesión 03)
Validar modelo de BCI / EEGPermutaciones + LOSO
Múltiples modelosCorrección B-H sobre p-permutaciones

⚠ Número de permutaciones

Para p-valor de 0.05 necesitas al menos B=1000 permutaciones. Para p=0.01, B=10,000. Con LOSO sobre señales largas, cada permutación puede ser costosa — considera paralelizar.
