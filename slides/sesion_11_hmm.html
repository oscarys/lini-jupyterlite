Módulo IIIEstructura del HMM2 / 8

El Modelo Oculto de Markov — λ = (π, A, B)

ComponenteSímboloSignificado
Distribución inicialπP(z₁ = k)
Matriz de transiciónAP(zₜ₊₁=j | zₜ=i)
Modelo de emisiónBP(xₜ | zₜ=k)

Los tres problemas canónicos (Rabiner, 1989)

1. Evaluación: dado λ y X, calcular P(X|λ)
→ Algoritmo Forward

2. Decodificación: dado λ y X, encontrar z* = argmax P(z|X, λ)
→ Algoritmo de Viterbi

3. Aprendizaje: dados X, encontrar λ* = argmax P(X|λ)
→ Algoritmo Baum-Welch (EM)

Supuesto de Markov

P(zₜ | z₁,...,zₜ₋₁) = P(zₜ | zₜ₋₁) — el futuro solo depende del estado presente. Para señales fisiológicas esto es una aproximación: el sueño tiene dependencias a largo plazo (ciclos de ~90 min) que el HMM de primer orden no captura directamente.

Rabiner, L.R. (1989). A tutorial on hidden Markov models. Proc. IEEE, 77(2), 257–286.

Módulo IIIAlgoritmo Forward-Backward3 / 8

Forward-Backward — Evaluación y Suavizado

Forward: α filtrado

αₜ(k) = P(x₁,...,xₜ, zₜ=k | λ) Init: α₁(k) = πₖ · b_k(x₁) Rec: αₜ₊₁(j) = b_j(xₜ₊₁) · Σₖ αₜ(k)·Aₖⱼ Term: P(X|λ) = Σₖ αT(k)

Backward: β suavizador

βₜ(k) = P(xₜ₊₁,...,xT | zₜ=k, λ) Init: βT(k) = 1 Rec: βₜ(k) = Σⱼ Aₖⱼ · b_j(xₜ₊₁) · βₜ₊₁(j)

Posterior suavizado

γₜ(k) = P(zₜ=k | X, λ) = αₜ(k)·βₜ(k) / P(X|λ)

Filtrado vs suavizado

Filtrado (solo Forward): usa x₁,...,xₜ → causal, puede usarse en tiempo real.
Suavizado (Forward-Backward): usa toda la secuencia → más preciso, requiere la secuencia completa.

Para estadificación del sueño offline, siempre se usa el suavizado.

Log-espacio — obligatorio

Las α decrecen exponencialmente con T. Con T=480 épocas, α₄₈₀ ≈ 10⁻¹⁰⁰⁰ — underflow garantizado en float64. La solución: trabajar en log-espacio y usar logsumexp para las sumas.

Módulo IIIAlgoritmo de Viterbi4 / 8

Viterbi — Decodificación Óptima Global

Problema de decodificación

ẑ = argmax P(z₁,...,zT | X, λ) ≠ [argmax_k γₜ(k)]ₜ (⟵ puede violar transiciones) δₜ(k) = max P(x₁,...,xₜ, zₜ=k, z₁,...,zₜ₋₁ | λ) ψₜ(j) = argmax [δₜ₋₁(k) + log Aₖⱼ]

Viterbi vs posterior argmax

Argmax γₜ(k)Viterbi
OptimizaCada t por separadoSecuencia global
Consistencia⚠ Puede violar A✅ Siempre válida
SuavidadMás suaveMás abrupta
Caso idealTiempo realAnálisis offline

Ejemplo clínico: estadificación del sueño

El argmax del posterior puede producir secuencias como "N3 → Wake → N3" (transición fisiológicamente improbable). Viterbi respeta que A[3,0] ≈ 0.01 — para pasar de N3 a Vigilia el modelo prefiere la ruta N3→N2→N1→Vigilia.

Perslev, M. et al. (2021). U-Sleep: resilient high-frequency sleep staging. npj Digital Medicine, 4, 72. doi:10.1038/s41746-021-00440-5

Baum-Welch — EM para HMM

EM aplicado al HMM

Paso E: γₜ(k) = P(zₜ=k | X, λ) ξₜ(k,j) = P(zₜ=k, zₜ₊₁=j | X, λ) Paso M: Â_{kj} = Σₜ ξₜ(k,j) / Σₜ γₜ(k) μ̂_k = Σₜ γₜ(k)·xₜ / Σₜ γₜ(k) Σ̂_k = Σₜ γₜ(k)(xₜ-μ̂_k)(xₜ-μ̂_k)ᵀ / Σₜ γₜ(k)

hmmlearn en Python

from hmmlearn import hmm
model = hmm.GaussianHMM(
    n_components=5,
    covariance_type='diag',
    n_iter=100
)
model.fit(X_todo, lengths)
z_hat = model.predict(X_test)

Con múltiples secuencias de longitud variable, pasar lengths como lista al método fit().

⚠ Permutación de etiquetas

Baum-Welch puede converger con los estados reordenados. Es necesario alinear los estados aprendidos con los verdaderos usando la asignación húngara (linear_sum_assignment) antes de calcular exactitud.

Múltiples inicializaciones

Baum-Welch converge a máximos locales. La práctica estándar es ajustar 5–20 modelos con distintas semillas y seleccionar el de mayor log-verosimilitud. Con K=5 estados de sueño, la fracción de convergencia al mismo óptimo es típicamente 60–80%.

Aplicaciones — Sueño y Microestados EEG

Estadificación del sueño de 5 estados (AASM)

Por qué HMM en lugar de clasificador frame-by-frame

  • Captura dependencias temporales entre épocas
  • Evita transiciones fisiológicamente imposibles
  • Produce hipnogramas más suaves y realistas
  • Cuantifica incertidumbre de transición como probabilidades

Microestados EEG — 4 estados, ~80 ms

Patrones topográficos casi estacionarios que se suceden a ~12 Hz. La alta auto-transición (A_{kk} ≈ 0.70–0.72) refleja la persistencia de cada microestado. El HMM izquierda-derecha modela correctamente la no reversibilidad en algunas configuraciones.

Berry, R.B. et al. (2015). AASM Scoring Manual v2.2. aasm.org
